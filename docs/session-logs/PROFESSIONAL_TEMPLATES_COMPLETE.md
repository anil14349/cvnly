## 🏗️ **Template Layouts (Structural Differences)**

### 1. **📄 Classic** (Single Column, Centered Header)
**Structure:**
```
┌─────────────────────────────────┐
│     [NAME - Centered]            │
│     [Title - Centered]           │
│     [Contact - Centered]         │
├─────────────────────────────────┤ ← 2px border
│                                 │
│  SUMMARY                        │
│  ────────────                   │ ← 1px section line
│  Content...                     │
│                                 │
│  EXPERIENCE                     │
│  ────────────                   │
│  Content...                     │
│                                 │
└─────────────────────────────────┘
```

**Features:**
- Traditional centered header
- Horizontal section dividers
- Georgia serif font
- Maximum ATS compatibility
- **Best for:** Corporate, Finance, Legal, Government
